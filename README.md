## What I'm building

**AI microservice for technical responsibility documents (ARTs)** — automated analysis of engineering documents for 16+ regional councils across Brazil, built with Python, Django REST Framework, LangChain and a RAG pipeline over legislation and technical references.

What it delivers:

- **~95% approval rate** on the generated analyses, as judged by technical reviewers
- **300+ documents analyzed per day**, with 200+ files going through extraction daily
- **30% less redundant traffic** after introducing caching
- Heavy analysis runs off the request cycle, so the API stays responsive no matter the document volume
- Full traceability of requests and operations across services, through auditing and structured logging

## Working with agentic AI

Part of my day is spent building with LLMs, and part of it building *through* them:

- **Agentic workflows** with LangChain and LangGraph — tool calling, structured outputs, retrieval as a tool and multi-step flows with state
- **Model Context Protocol (MCP)** — wiring models to external tools and data sources instead of stuffing everything into the prompt
- **Prompt engineering** treated as an engineering problem: versioned prompts, structured schemas and outputs measured against reviewer feedback
- **AI coding agents** in daily work — agent harnesses, skills and custom instructions, plus the judgment of when the agent is the wrong tool for the task
